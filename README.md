# joshlucem.github.io

Personal site. Plain HTML, CSS and a little JavaScript, no dependencies. The pages are built with a small Python script that is not part of this repository.

```
/                          /es/                       home
/projects/                 /es/proyectos/             projects
/projects/skylease/        /es/proyectos/skylease/    Skylease
/contact/                  /es/contacto/              contact
/notices/                  /es/avisos/                privacy, trademarks, licences
404.html                                              not found
assets/                                               styles, scripts, fonts, images
```

Preview locally with `python3 -m http.server 4000` from this folder, then open http://localhost:4000.
